# 🏏 IPL 2023 Data Analysis

An end-to-end **IPL 2023 Data Analytics project** using **MySQL and Power BI**.

## 📌 Project Overview

This project analyzes IPL 2023 data to understand:

* Team performance
* Player batting performance
* Bowling performance
* Match results
* Toss vs match winner
* Venue analysis
* Match scorecards

## 🛠️ Tools Used

* **MySQL** – Data storage and SQL analysis
* **Power BI** – Dashboard and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculations

## 📂 Dataset

The project contains four datasets:

* Matches
* Batsman
* Bowler
* Scorecard

## 📊 Dashboard Pages

1. **Home**
2. **Tournament Overview**
3. **Team Analysis**
4. **Bowling & Match Analysis**

## 🔍 Key Insights

* Gujarat Titans recorded the highest number of wins with **10**.
* Faf du Plessis was the top run scorer with **730 runs**.
* Rashid Khan took the most wickets with **25**.
* The dataset contains **70 IPL 2023 matches**.
